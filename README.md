# 乾杯牌局

朋友聚會時，用一支手機輪流抽牌的酒桌遊戲。開始時可設定 2～12 位玩家與名字；空白名字會自動使用「玩家 1、玩家 2……」。內含完整 52 張撲克牌、13 種牌面規則、K 與陪酒小姐計數，以及會標示持有者的照相機、摸鼻子、神經病等持續效果。

遊戲途中可隨時從頁首的「調整玩家」增減人數、修改名字或重新排列抽牌順序。「最近抽牌」預設收合，需要時再展開查看。

## 使用方式

直接開啟 `index.html` 即可試玩。透過 GitHub Pages 發布後，也能加入手機主畫面；首次開啟並載入完成後，可在離線狀態繼續使用。

## GitHub Pages 發布

1. 在 GitHub 建立一個新的公開 repository。
2. 將本資料夾內的所有檔案上傳到 repository 根目錄。
3. 前往 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選擇 `main`，資料夾選擇 `/ (root)`，按下 **Save**。
6. 等待約一至數分鐘，GitHub 會顯示可分享的網址。

## 說明

- 遊戲進度儲存在目前裝置的瀏覽器中，重新整理不會消失。
- 「重新洗牌」會清除本局所有進度與場上效果。
- 本遊戲不需要伺服器，也不會蒐集或上傳個人資料。
- 各桌的玩法可能不同，開始前請先確認規則；飲酒請量力而為。
